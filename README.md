# Ubuntu Rust DevContainer

A ready-to-use [DevContainer](https://containers.dev/) for Rust software development on Ubuntu.

## Available Versions 

* [Ubuntu 26.04 LTS - Rust 1.93.1](https://github.com/canonical/ubuntu-rust-devcontainer/tree/ubuntu-26.04-rust-1.93)
* [Ubuntu 26.04 LTS - Rust 1.93.1 Distro](https://github.com/canonical/ubuntu-rust-devcontainer/tree/ubuntu-26.04-rust-1.93-distro)
* [Ubuntu 26.10 - Rust 1.97.1](https://github.com/canonical/ubuntu-rust-devcontainer/tree/ubuntu-26.10-rust-1.97)
* [Ubuntu 26.10 - Rust 1.97.1 Distro](https://github.com/canonical/ubuntu-rust-devcontainer/tree/ubuntu-26.10-rust-1.97-distro)
