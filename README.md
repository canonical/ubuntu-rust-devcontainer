# Ubuntu Rust DevContainer

A ready-to-use [Dev Container](https://containers.dev/) for Rust software development on Ubuntu.

## Available Versions 

* [Ubuntu 26.04 - Rust 1.93.1](https://github.com/canonical/ubuntu-rust-devcontainer/tree/ubuntu-26.04-rust-1.93)
* [Ubuntu 26.04 LTS - Rust 1.93.1 Distro](https://github.com/canonical/ubuntu-rust-devcontainer/tree/ubuntu-26.04-rust-1.93-distro)
